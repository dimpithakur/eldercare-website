# ElderCare Website

ElderCare is a web-based project designed to support elderly people with daily assistance, reminders, safety features, and community engagement.

This project was created using HTML, CSS, and JavaScript.

##Features

- Elder Profile Creation
- Assistance Section
- Community Engagement
- Reminder System
- SOS / Safety Feature
- User-Friendly Interface
- Responsive Navigation Bar
- Clean and Simple Design

##Pages Included

- Profile Page
- Assistance Section
- Community Section
- Reminder Section
- SOS / Safety Section

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose of the Project

The purpose of this project is to help elderly people manage daily activities and improve communication, safety, and accessibility through a simple web interface.
